## Design de nível premium

Cada site deve ter uma identidade visual própria. Não reutilize cegamente o mesmo layout entre projetos.

Não transforme todos os negócios em: Hero → 3 cards → Serviços → Depoimentos → CTA → Footer. Essa estrutura pode existir quando fizer sentido, mas não deve determinar o design.

**O design deve nascer do negócio.** Analise:

- segmento;
- público;
- posicionamento;
- personalidade;
- diferenciais;
- localização;
- objetivo;
- concorrência;
- conteúdo disponível.

Depois crie uma linguagem visual coerente.

Quero identidade.

## Animações premium

**ANIMAÇÕES SÃO PERMITIDAS E DESEJADAS QUANDO ELAS MELHORAREM A EXPERIÊNCIA.**

Mas **NÃO** coloque animações apenas para dizer que o site tem animações. Quero animações sofisticadas, naturais e com propósito.

Quando apropriado, utilize:

- GSAP;
- ScrollTrigger;
- timelines;
- scrub;
- pin;
- parallax;
- layered parallax;
- clip-path;
- masks;
- image reveal;
- text reveal;
- scale transitions;
- sticky storytelling;
- horizontal storytelling;
- microinterações;
- hover interactions;
- cursor interactions;
- transições cinematográficas;
- Lottie;
- vídeo;
- WebGL/Three.js.

Escolha a tecnologia adequada. Não force uma biblioteca.

### Animação não é fade-in

Não faça isso:

```
SEÇÃO → FADE-IN
SEÇÃO → FADE-IN
SEÇÃO → FADE-IN
SEÇÃO → FADE-IN
```

Isso é básico. Procure criar movimento com:

- profundidade;
- transformação;
- continuidade;
- ritmo;
- interação;
- contexto;
- narrativa.

Cada animação importante deve responder: **"Por que isso está se movendo?"** Se a resposta for "porque fica bonito", pense novamente.

### Animação cinematográfica

Quando houver oportunidade, crie momentos cinematográficos. Exemplos:

- uma imagem revelando outra;
- uma transformação visual controlada pelo scroll;
- uma seção que muda de estado;
- uma imagem atravessando camadas;
- uma composição que se reorganiza;
- uma transição que conecta duas ideias;
- uma narrativa visual baseada em scroll;
- uma comparação antes/depois;
- elementos reagindo uns aos outros.

Quero que alguns momentos do site sejam memoráveis. Não quero um carnaval de efeitos. **1–3 momentos excelentes valem mais que 30 efeitos medíocres.**

### Movimento natural

As animações precisam ter sensação de qualidade. Use cuidadosamente:

- easing;
- duração;
- aceleração;
- desaceleração;
- stagger;
- inércia;
- profundidade;
- escala;
- timing.

Evite movimentos robóticos. Evite tudo se mover simultaneamente. Evite que tudo tenha a mesma velocidade. Crie ritmo.

## Experiência humana

Projete para pessoas, não para componentes. O visitante deve sentir:

- clareza;
- confiança;
- curiosidade;
- interesse;
- segurança;
- desejo de continuar navegando.

Nos primeiros segundos, ele precisa entender:

1. O QUE É?
2. PARA QUEM É?
3. POR QUE IMPORTA?
4. O QUE EU POSSO FAZER?

Depois conduza naturalmente: **INTERESSE → CONFIANÇA → PROVA → DESEJO → AÇÃO.**

Nunca complique a experiência apenas para parecer sofisticado.
